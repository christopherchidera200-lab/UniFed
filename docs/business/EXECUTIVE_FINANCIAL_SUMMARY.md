# UniFed Nigeria — Executive Financial Summary

> One-page synthesis of the 17 supporting documents. All cost/revenue figures are **planning
> estimates** grounded in the repository audit (see `CODEBASE-INVENTORY.md`, `COVERAGE.md`,
> `CLOUD_COST_ANALYSIS.md`). No metrics are fabricated.

## The $0 → national arc
```
$0 prototype (local Docker)        → today
low-cost ADUN pilot (~$400/mo)     → deploy now (right-sized, not as-coded ~$1.7k/mo)
funded production pilot            → grant/angel
multi-university (Stage 2)         → seed
national infrastructure (Stage 4+) → Series A
Africa-scale federation            → growth capital
```
Each stage unlocks the next: pilot de-risks revenue; federation lowers CAC; scale lowers unit cost.

## Key numbers (Base case)
- **Pilot infra:** ~$4.8k/yr (right-sized) vs ~$19–23k/yr as-coded.
- **Cost/university/yr:** ~$14.8k fixed + ~$0.85–$11.90/active-student variable.
- **Break-even:** ~23 universities (blended $45k) or ~8 Enterprise ($80k).
