## 1. Market context (evidence-based)

- Nigeria has **~200+ universities** (federal, state, private) — public, documented denominator
  [M1]. West Africa adds several hundred more.
- Large youth/student population; mobile-first; under-served by integrated campus software.
- Fragmented现状: most unis run disjointed tools (portal + LMS + social + career + manual records).
- Government push for digital transformation, TETFund/ITF/NITDA EdTech funding.

## 2. Market structure

| Layer | Description |
|---|---|
| TAM | All African higher-ed institutions + their students/staff (hundreds of unis, millions of users) |
| SAM | Nigerian (then West African) universities wanting an integrated, sovereign, federated OS |
| SOM | Pilot (ADUN) → 3–10 unis near-term → 50+ at scale |

[M2] TAM/SAM/SOM are **directional**; a funded market study should replace these ranges.

## 3. Demand drivers
- Digital transformation mandates.
- Student expectation for consumer-grade UX (social + services in one app).
- Employability pressure → career/employer integration valued.
- Data sovereignty / NDPA → unis want to own data (federation fits).
- Cost pressure → replace multiple tools with one OS.

## 4. Adoption barriers
- Long public-sector procurement cycles.
- Risk-averse ICT directorates; change management.
- Interop with legacy systems (ASIS/SPGS, SIS).
- Budget constraints (FX, dollar costs).
- Trust/security concerns (handled via STRIX + NDPA work).

## 5. Nigerian/African opportunity (why now)
- No dominant "University OS" with federation in the region.
- ActivityPub federation is proven (Mastodon) but unused in HE → first-mover angle.
- Grant/development-agency funding available for digital education / DPI.
- Mobile-first, English-friendly, locally-built → distribution advantage.

## 6. Market readiness
- **Product:** M1 done; pilot not yet live → early.
- **Buyers:** reachable via VC/ICT; procurement slow.
- **Funding:** grants + early institutional budgets plausible.
- **Competitive window:** open now; closes if a regional LMS vendor adds federation or a global
  player localises.
