## 1. Contribution per university (illustrative, Medium uni)
- Price (avg booked): **$35k/yr** [B1]
- Infra+support per uni (Stage 2): **~$13k/yr** (UNIT_ECONOMICS)
- Allocated personnel/compliance per uni (amortise team): **~$30k–$60k** depending on uni count
- **Contribution/uni ≈ $35k − $13k − alloc ≈ $5k–$22k** before full load.

At low uni counts, personnel is a fixed pool → contribution barely covers it. Break-even needs
enough unis that **total contribution > fixed personnel + opex**.

## 2. Break-even by university count (Base scenario)
Fixed annual cost (Y2-ish steady): personnel $1.1M + opex $450k + infra $200k ≈ **$1.75M**.
Contribution/uni (after infra+support, before alloc) ≈ $22k.
- **Break-even ≈ 1.75M / 22k ≈ ~80 paid unis** at pure subscription, Base cost structure.
- With **premium modules + Enterprise pricing ($40k–$120k)**, contribution/uni rises → break-even
  **~40–60 unis**.
- With **grants covering opex**, effective break-even **~30–50 unis**.

> Implication: **pure subscription needs 40–80 paid unis to break even**; the realistic path is
> **mix of Enterprise pricing + premium modules + grant non-dilutive funding** to reach it at
> 30–50 unis. This aligns with the 3-year projection (still pre-break-even at Y3 base = 32 paid).

## 3. Paying-student view
- If per-student component ~$3/yr and a uni has 20k students → $60k/uni (above Starter range);
  but public unis resist → treat as overflow only. Student count alone doesn't drive break-even;
  **uni count + tier + modules do.**

## 4. MRR / ARR framing
- 50 paid unis × $35k = **$1.75M ARR** (Base). Need ~$2M+ ARR to cover Base Y3 cost → consistent
  with ~50–60 unis incl. premium.
- Gross margin (infra) ~78%; operating margin negative until scale/premium/grants.

## 5. Strongest pricing strategy for break-even
1. **Tiered institutional subscription** (floor + Enterprise uplift).
2. **Premium modules** (AI/analytics/career/research/federation) — high-margin, low-infra.
3. **Federation network fee** for consortia.
4. **Grants** to offset opex (non-dilutive).
5. Avoid per-student-only pricing (political + margin risk on small unis).

## 6. Sensitivity
- If avg price falls to $20k → break-even ~70–120 unis (worse).
- If premium attach adds $15k/uni avg → break-even ~30–45 unis (better).
- If grants cover $300k opex → break-even ~10–15 fewer unis.
