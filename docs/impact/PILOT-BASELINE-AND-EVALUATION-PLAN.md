# UniFed Nigeria — Pilot Baseline & Evaluation Plan (DRAFT)

---

## 1. Purpose
Establish baseline measurements for the impact KPIs (see framework) and validate the platform
with a single university (Admiralty University of Nigeria) before multi-university scaling.

## 2. Pre-pilot baseline (PENDING INSTITUTIONAL APPROVAL)
- Capture existing manual-process metrics (e.g. library loan time, ID issuance time, notice delivery).
- Agree KPI targets with ADUN (PENDING INSTITUTIONAL APPROVAL).
- Instrument analytics + security logging before go-live.

## 3. Onboarding
- Deploy pilot per `docs/STAGING-DEPLOYMENT-REPORT.md` runbook (Coolify/EC2).
- Import/seed ADUN directory (PENDING INSTITUTIONAL APPROVAL for real data).
- Train faculty/admin super-users.

## 4. Pilot monitoring (12 weeks suggested)
- Weekly KPI snapshot (adoption, academic, identity, library, career, security).
- Automated dashboards; anomaly alerts.

## 5. User research
- Onboarding surveys (N target 200), mid-pilot CSAT, exit interviews (faculty + students).
- Focus groups on federation value and data-sovereignty concerns.

## 6. Post-pilot evaluation
- Compare pilot KPIs vs pre-pilot baseline.
- Security post-mortem (re-run STRIX-style validation in pilot environment).
- Cost-per-student actuals vs model (see `docs/business/UNIT_ECONOMICS.md`).

## 7. Comparison & lessons
- Quantify efficiency gains; document blockers; produce go/no-go for university #2.
